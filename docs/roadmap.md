# 路线图（Roadmap）

> 这是**公开**的路线图（版本与里程碑的对应关系见 [`versioning.md`](versioning.md)）。
> **⚠️ 非承诺**：个人项目，节奏会随真实用户反馈调整；完成度以本文件与实际 Release 为准。
> 变更历史见 [`../CHANGELOG.md`](../CHANGELOG.md)。

## 这个项目是什么

面向**在法国学习的中国学生**的本地课程资料问答助手：把法语课程资料（PDF / DOCX / PPTX / 图片）
解析成统一结构，再基于它们回答问题，**答案带可点击的页码引用**。
资料与向量都在本机，**不上传云端**；检索与生成的可量化指标、成本账全部公开（见下方"可复现"一栏）。

## v0.1.0 —— 工程 MVP ✅（2026-09-14）

上传 → 解析 → 落库 → 切块 → 向量化 → 检索 → **带来源回答**，界面接真实数据。

| 能力 | 状态 |
|---|---|
| 多格式解析（PDF / DOCX / PPTX / 图片 OCR）、异步上传 + 进度 | ✅ |
| 本地 embedding（`multilingual-e5-large`）+ sqlite-vec 检索 | ✅ |
| 带引用回答；**点引用跳到原文页**；正文内 `[来源 N]` 可点 | ✅ |
| Agent 自主调用检索工具（有界循环 + 失败降级直答） | ✅ |
| 六个工具按 **MCP 协议**暴露（stdio） | ✅ |
| 会话与消息落库、刷新后恢复；模型可在界面配置 | ✅ |
| 结构化 trace（`gen_ai.*` 对齐 OTel） | ✅ |

**可复现的公开指标**（语料随仓库分发，clone 后能自己跑出来）：

| 层 | 指标 |
|---|---|
| L1 检索（合成语料 30 条） | HitRate@1 `76.9%` / @5 `92.3%` / @10 `100%` / MRR `0.850` |
| L2 生成（合成语料 30 条） | 答案带引用 `26/26`、引用召回 `93.5%`、文档命中 `92.5%` |
| 成本与延迟 | 单次提问 **≈ ¥0.01**；端到端 P50 `5.6 s`（TTFT 尚未测，无流式） |

> 私人课件的评测（46 条）不做公开分发，因为它有著作权；那份报告的**方法**与代码是公开的。

## v0.2.0 —— R1：追平基础 + 一个差异化 ⬜ 进行中

**目标**：让"陌生人能装起来、用得下去、出错能自己恢复"，并在基础之上留**一条别人没有的证据**。

| 类别 | 内容 |
|---|---|
| 基础（对齐开源同类中位数） | 会话管理（新建/切换/历史）· 多工作区（按课程收窄检索范围）· 流式输出 · 上传失败重试 · 图片/扫描件 OCR 端到端验证 · 重复上传行为明确 |
| 差异化 | **quiz / 中法术语自测**：只从你自己的课件生成自测题，术语给中文对照 |
| 体验 | demo 录屏、干净环境一键跑通、错误与空状态 |
| 数据安全 | 升级时数据库迁移可预期（见 `versioning.md` §5） |

## v0.3.0 —— R2：差异化产品化 ⬜ 未开始

由 **R1 期间的真实用户反馈**决定取舍方向，当前候选：

- 法语术语的"考试化"产物（术语卡 / 自测 / 错题重做）；
- 文档管理长尾（删除、去重、批量）；
- 图片**内容**理解（不只是 OCR 文本）；
- 课程阅读桌的进一步形态（按学期 / 按资料类型组织）。

## 明确不做（沿用既有决定，欢迎质疑）

| 不做 | 原因 |
|---|---|
| 多用户 / 认证 / 协作分享 | 单人单机是当前形态；要先有真实用户 |
| 章节树切块 / reranker / 混合检索 | 需先用评测证明收益 > 10pp，否则是凭感觉加复杂度 |
| Tauri 桌面端 | 维护成本（打包、三平台）远高于它带来的价值 |
| 云端部署 / 规模化 | 与"资料不出本机"的定位冲突 |
