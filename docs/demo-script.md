# demo 录屏脚本（分镜 + 录制清单）

> **为什么要有这份东西**：风险登记里最红的一条是"70% 初筛死于跑不起来的项目"。
> 录屏是唯一能证明"这套东西真的能跑"的产物 —— 但它必须**可复现**，所以每个画面都要对应仓库里
> 已有的命令、自产语料和公开报告。
>
> ⚠️ **录制前必读**：只能上传**自产合成语料**（`eval/fixtures/synthetic/`），
> **不要出现私人课程课件**（有著作权，也不该出现在公开镜像里）；界面里也不要出现任何 `api_key`。

## 一、录制前准备（一次性，约 5 分钟）

```bash
# 1) 一键起前后端（前端 http://localhost:5173 / 后端 http://127.0.0.1:8000）
python scripts/run_demo.py

# 2) 若只是想确认命令对不对，不真启动：
python scripts/run_demo.py --check
```

打开界面后：

1. 点右上角「设置」→ 模型配置 → 填一个 OpenAI 兼容端点 → **激活**
   （录像里这一步可以剪短，但**必须完整出现"激活成功"**，否则观众会以为你在用假数据）；
2. 用左侧"上传"传 `eval/fixtures/synthetic/pdf/` 下的 **2–3 份讲义**
   （六份全传也行，154 页约 1 分钟，正好演示进度条）；
3. 清空一次会话历史（`localStorage` 里的 `greenbean.chat.session_id`）—— 从零开始更像真实使用。

## 三、录制参数

- 分辨率 **1920×1080**（或 1280×720），浏览器缩放 100%；
- **不要**开"演示模式"的假按钮 —— 界面里没有的功能就不要出现在镜头里；
- 提问前先想好问题文本，避免录进去反复打字的犹豫；
- 字幕用中文，**法文用户提问**至少出现一次（体现真实场景）。

## 四、自检清单（录完逐条打勾）

- [ ] 画面里没有私人课件（只有 `eval/fixtures/synthetic/` 的自产讲义）
- [ ] 画面里没有任何 `api_key` / 完整主机名 + key
- [ ] 引用点击后**确实跳到了对应页**（不是只高亮了引用条目）
- [ ] 拒答那一段是真的问了一个语料里没有的问题（不是问"你不会的问题"）
- [ ] 报告页里的每个数字都能在仓库文档里找到出处（上面表格右列）
- [ ] 视频时长 ≤ 3 分 30 秒；前 10 秒就出现了界面（面试官不会等）

## 五、如果你只有 60 秒

只录 **第 3 段**（提问 → 带引用回答 → 点引用跳原文）＋ **第 5 段**（拒答）。
这两个画面分别是"它有用"和"它不胡说"的证据，也正好对应两条评测指标。
